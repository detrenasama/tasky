# AGENTS.md

TUI-приложение «Tasky» на Go: менеджер задач с учётом времени.

## Команды

- `go run .` — запуск приложения (требуется настоящий TTY)
- `go build -o tasky .` — сборка бинарника (заметь: `go build ./...` НЕ создаёт файл в каталоге)
- `go vet ./...` и `gofmt -l .` — проверки перед завершением задачи
- `go test ./...` — тесты (internal/db/schema_test.go)

## Структура и стек

- `main.go` — корневая BubbleTea-модель: переключение экранов (`tasks`/`projects`/`reports`/`settings`), тик 1с (обновление таймеров и недельной суммы), `tea.WindowSizeMsg`, выход по `q`/`ctrl+c`; здесь же общие стили lipgloss и фиксированная хрома: `View()` = вкладки (1 строка, `tabsLine` — текущая страница accent, остальные dim) + шапка (1 строка) + средняя область (`h-3`) + подвал (подсказки клавиш); если открыта модалка — поверх всей хромы `overlay()` из `modal.go`
- `tasks_screen.go` — главный экран: три колонки в средней области на всю ширину (пороги: `w≥110` — list|описание|info в пропорции 2:2:1, `70≤w<110` — list+info (2:1), `w<70` — только list; математика в `resize()`); список с раскрывающимися подзадачами (`enter`/`→`, `▸`/`▾`, подзадачи с `├`); info-панель: для подзадачи — статус + список time entries (`TimeEntriesBySubtask`), для задачи — статус + подзадачи со временем; внизу «Общее» (высота по контенту) — недельная сумма (`s.weekly`) и текущая запущенная подзадача (`s.run` из `RunningSession`); верхняя часть info-колонки растягивается на оставшуюся высоту; колонка «Описание» — зарезервированная dim-заглушка; `n`/`a` — новые задача/подзадача, `d` — удаление, `ctrl+l` — старт/пауза, `[`/`]` — проект, `p` — проекты; ввод и подтверждения — модальные окна (методы `header`/`footer`/`view`/`dialog`, вызываются из `main.go`)
- `projects_screen.go` — экран проектов: `n` создать, `d` удалить; ввод/подтверждение — модальные окна; три колонки в средней области: `w≥110` — list|описание|сводка 1:3:1 (`u=(w-4)/5`, list += остаток), `60≤w<110` — list+info (1:1), `w<60` — только list; средняя (`descBox`) и правая (`infoBox`) — пока dim-заглушки (описание со ссылками/контактами и сводка с коэффициентом времени)
- `reports_screen.go`/`settings_screen.go` — страницы «Отчеты»/«Настройки», пока заглушки (header/footer/view/dialog без данных); `esc` на любой не-tasks странице возвращает к задачам (обработка в `main.go`)
- Глобальные клавиши вкладок `t`/`p`/`r`/`s` — переключение страниц в `main.go` (не в экранах!), гвард `modalOpen()` (не переключать при открытой модалке ввода/подтверждения); `p` в tasks_screen больше НЕ обрабатывается
- `modal.go` — `overlay(base, dialog, w, h)`: центрирует диалог по середине холста, затемняет фон (`faintStyle`), фрагменты фона под диалогом обрезаются (используется `stripANSI`/`ansiEnd` — свои, т.к. `muesli/ansi` не имеет Strip); `dialog` — заголовок + содержимое + кнопки `[ Enter — сохранить ]`/`[ Esc — отмена ]` (у подтверждений `[ y — да ]`/`[ n — нет ]`)
- `ui.go` — `padW`/`truncateW` (обрезка по видимой ширине с учётом ANSI и широких рун, `go-runewidth`), `padH` (приведение к холсту w×h — обязательно для фиксированных шапки/подвала) и `fixedBox`/`padLines` (рамка ровно w×h)
- `internal/db` — пакет `db.Open(path)` поверх `database/sql` + `modernc.org/sqlite` (чистый Go, без CGO); типы в `types.go`, запросы: `projects.go`, `tasks.go`, `time.go`
- БД: файл `tasky.db` в рабочем каталоге; схема (projects → tasks → subtasks → time_entries) создаётся автоматически при открытии (см. `schema.go`)
- UI: `bubbletea` + `bubbles` (list, textinput) + `lipgloss`; запуск через `tea.NewProgram(..., tea.WithAltScreen())`
- Списки (`bubbles/list` v1.0.0): делегат — `list.NewDefaultDelegate()`, описание элемента — методы `Title()`/`Description()` интерфейса `DefaultItem` (старого `SetDescriptionFunc` нет); ВАЖНО: `View()` НЕ дополняет строки до `SetWidth` — ряды рендерятся по контенту, паддинг вручную через `padLines` (см. `view()` в tasks_screen); хром `boxStyle` = 4 (бордер 2 + паддинг 2) — контент рамки паддится до `w-4`

## Нюансы

- SQLite открывается через DSN с прагмами `foreign_keys(1)` и `busy_timeout(5000)` (см. `db.go`) — не отключать: без FK каскады не работают.
- Активная сессия учёта времени — это запись `time_entries` с `ended_at IS NULL`; не более одной на подзадачу (unique partial index), а `StartSession` в транзакции останавливает любую другую активную сессию — одновременно идёт максимум одна подзадача.
- Недельная сумма (`WeeklyTotal` в `time.go`) и «За сегодня» (`TodayTotal`): общий `rangeTotal(conn, from, to, now)` — записи, пересекающие интервал, обрезаются по границам; неделя с понедельника 00:00 локального времени; активная сессия учитывается частично (до текущего момента).
- `padLines` клампит `w`/`h` (0/отрицательные) — при старте BubbleTea вызывает `View()` с размером 0×0 до первого `WindowSizeMsg`, и ветка с данными в `view()` иначе паникует на `lines[:h]`.
- Экраны — указатели (`*tasksScreen`): описания элементов подзадач читают `now` через замыкание на экран, поэтому без указателя обновления таймера не будут видны.
- ID задач и подзадач — отдельные последовательности и могут совпадать: поиск/выделение по ID всегда по паре `(kind, id)` (`selectedKindID`/`indexByKindID`/`selectByKindID` в `tasks_screen.go`), иначе курсор попадает в чужой элемент.
- `list.Select(0)` на пустом списке ставит `Index()=0` при `len(items)==0` — перед `Select` и индексацией по выбранному элементу всегда проверять длину (`canDelete()` в `tasks_screen.go`).
- Тестировать TUI в неинтерактивной оболочке нельзя (`/dev/tty` недоступен). Минимальная проверка: `printf 'q' | timeout 10 script -qec "stty rows 30 cols 100; ./tasky" /dev/null` — код 0. При прогоне клавиатурных сценариев: `(sleep 0.6; printf 'n'; ...; printf 'q') | timeout N script -qec "stty rows 30 cols 100; ./tasky" /dev/null`; паузы ≥0.3с между клавишами (ранние нажатия теряются до инициализации TUI); Enter посылать как `\r`, не `\n` (в raw-режиме `\n` — это ctrl+j); `stty rows 30 cols 100` обязателен — без него pty имеет размер 0x0 и ломает рендер. Для сценария с клавишами, где нужна схема БД, сначала создать её прогоном `printf 'q' | ... ./tasky`, затем сид через python3.
- `tasky.db` и бинарник `tasky` в `.gitignore`.
- Режим приложения только альтернативный экран (WithAltScreen).
