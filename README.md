# Tasky

TUI-менеджер задач с учётом времени на Go (Bubble Tea + SQLite).

Задачи и подзадачи в проектах, настраиваемые статусы с быстрой сменой по цепочке, теги внешних сервисов, учёт времени по подзадачам и отчёты за период с сохранением в файл.

## Возможности

- Проекты, задачи, подзадачи; полнотекстовый поиск (`/`)
- Каталог статусов с цветами и быстрой цепочкой (`x`/`z`), история переходов
- Теги задач (Jira, трекеры — тип, значение, URL)
- Учёт времени (`ctrl+l` старт/пауза), отчёты за день/неделю/месяц/свой период
- Скрытие давно завершённых задач, записи журнала подзадач

## Установка

Требуется Linux (amd64).

**Готовым бинарником** — скрипт качает последний релиз с GitHub, проверяет SHA256 и ставит в `~/.local/bin`:

```sh
curl -sSL https://raw.githubusercontent.com/detrenasama/tasky/main/scripts/install.sh | sh
```

**Из исходников** (нужен Go и `just`):

```sh
just build
just install        # в ~/.local/bin
```

**Через go install** (нужен Go):

```sh
go install github.com/detrenasama/tasky@latest
```

## Обновление

```sh
tasky upgrade
```

Команда проверяет последний релиз на GitHub, скачивает, проверяет контрольную сумму и атомарно заменяет бинарник. О наличии новой версии приложение также сообщает в подвале экрана задач.

Версия: `tasky --version`. Справка по командам: `tasky help`.

## Данные

База и отчёты хранятся в `~/.local/share/tasky/` (`tasky.db`, `reports/`). Каталог можно переопределить переменной окружения `TASKY_HOME` — например, для изолированного запуска:

```sh
TASKY_HOME=/tmp/tasky-dev tasky
```

Отчёты также можно сохранять в произвольный каталог из настроек приложения.

## Темы

Плоский интерфейс с цветовыми темами (по умолчанию `opencode`). Встроенные темы: `opencode`, `classic` (прежний вид), `nord`, `dracula`, `one-dark`. Смена — страница «Настройки» → строка «Тема».

Своя тема — JSON-файл в `~/.config/tasky/themes/` (каталог переопределяется `TASKY_CONFIG_HOME`):

```json
{
  "name": "my",
  "colors": {
    "accent": "#5c9cf5",
    "error": "#e06c75",
    "success": "#7fd88f",
    "warning": "#f5a742",
    "text": "#eeeeee",
    "muted": "#808080",
    "background": "#0a0a0a",
    "panel": "#141414",
    "element": "#1e1e1e",
    "selection": "#282828",
    "border": "#484848",
    "borderSubtle": "#3c3c3c"
  }
}
```

Все цвета опциональны — недостающие берутся из темы по умолчанию. Активная тема сохраняется в базе; переменная окружения `TASKY_THEME` временно переопределяет её.
