# История изменений Tasky

Формат: `## vX.Y.Z — ГГГГ-ММ-ДД`, ниже пункты списком. Файл встраивается в
бинарник (окно «Что нового») и используется для заметок GitHub-релиза.

## v0.6.0 — 2026-10-20

- Проверка обновлений при запуске: доступная версия показывается в правой панели под текущей.
- После обновления при первом запуске открывается окно «Что нового» с изменениями между версиями.
- Список изменений ведётся в `changelog/CHANGELOG.md` и попадает в заметки GitHub-релиза.
- Команда «Что нового» в палитре команд показывает полную историю версий.
- Команда «Обновить» в палитре: прогресс-бар этапов, отмена по двойному Esc до проверки контрольной суммы и выход после установки.

## v0.5.4 — 2026-10-20

- Лента: события по задачам, срокам и запланированным подзадачам, фильтры и архив.
- Сроки и даты планирования задач и подзадач.
- Скрытие давно завершённых задач (`ctrl+h`), остановка таймера (`ctrl+k`).
- Контекст родительской задачи в правой панели при выбранной подзадаче.
- Исправлен запуск сервера из индикаторов GNOME Shell и Windows.

## v0.5.3 — 2026-09-11

- Веб-интерфейс: отчёты, чек-листы и записи времени.
- Компактное отображение длинного списка записей времени.

## v0.5.2 — 2026-09-02

- Веб-интерфейс: описания, ссылки, теги, статусы и drag-and-drop задач.
- Сворачивание задач клавишей Tab.

## v0.5.1 — 2026-08-29

- Исправлена упаковка архива релиза.

## v0.5.0 — 2026-08-29

- Добавлен веб-интерфейс: JSON API, статика в бинарнике, React + TypeScript.
- Светлая тема, верхняя шапка и обновлённая навигация веб-интерфейса.
