# Tasky GNOME indicator

Индикатор [Tasky](https://github.com/detrenasama/tasky) в панели GNOME Shell: показывает «время за сегодня» и название запущенной подзадачи (до 16 символов). Индикатор всегда видим в панели; из его меню можно запустить/остановить сервер Tasky и открыть веб-интерфейс в браузере. Клик открывает меню с деталями (полное название подзадачи и время за сегодня).

Расширение написано на GJS (GNOME Shell 45+).

## Требования

- GNOME Shell ≥ 45 (проверено на 50)
- Установленный `tasky` — индикатор ищет его в `PATH`, затем в `~/.local/bin/tasky` (`just install`), `/usr/local/bin/tasky` (`PREFIX=/usr/local`), `~/go/bin/tasky` / `$GOPATH/bin/tasky` (`go install`), `/usr/bin/tasky`:
  ```sh
  tasky serve   # либо запустите сервер прямо из меню индикатора
  ```

## Установка

```sh
cd indicators/gnome
./install.sh
```

Скрипт копирует расширение в `~/.local/share/gnome-shell/extensions/` и включает его. Если расширение не появилось сразу — перезапустите сессию GNOME (выход/вход) или нажмите `Alt+F2` → `r`.

## Меню индикатора

- **Сейчас:** — название запущенной подзадачи (если есть).
- **За сегодня:** — суммарное время за день.
- **Запустить сервер** — запускает `tasky serve` (недоступно, пока сервер уже работает — хоть свой, хоть внешний).
- **Остановить сервер** — останавливает **только** сервер, запущенный этим индикатором (SIGTERM); если сервер запущен вне индикатора (например, `tasky serve` в консоли) — пункт недоступен.
- **Открыть в браузере** — открывает веб-интерфейс `http://<TASKY_HTTP_ADDR>` (по умолчанию `http://127.0.0.1:9110`).

При отключении расширения запущенный через него сервер останавливается. При запуске индикатор передаёт серверу текущие `TASKY_HTTP_ADDR`/`TASKY_SOCKET`/`TASKY_HOME` (как `--http-addr`/`--socket`); изменения этих переменных подхватываются динамически при каждом опросе и следующем запуске. `export` в терминале до `gnome-shell` не дойдёт — задавайте переменные через `~/.config/environment.d/*.conf` или `systemctl --user import-environment VAR` и перезапустите оболочку (выход/вход или `Alt+F2` → `r` на X11).

## Удаление

```sh
./uninstall.sh
```

## Как это работает

- Расширение раз в секунду делает HTTP-запрос `GET /status` к серверу Tasky (асинхронно, через `Gio.SocketClient`). Состояние кнопок «Запустить/Остановить» определяется этим опросом: если `/status` отвечает — сервер считается запущенным.
- Адрес по умолчанию — `http://127.0.0.1:9110`, переопределяется переменной `TASKY_HTTP_ADDR` (читается при каждом опросе; см. замечание про `environment.d` выше). Сокет — `TASKY_SOCKET`/`TASKY_HOME`.
- Сервер отвечает тем же JSON, что и команда `tasky status`:
  ```json
  {"today_seconds":3720,"subtask":{"id":6,"title":"Правки в README"}}
  ```
  Без запущенной подзадачи — `"subtask":null`.
- Название в панели обрезается по кодовым точкам до 16 символов с многоточием; в меню показывается полностью.

## Разработка

- `extension.js` — код расширения (ESM, `enable()`/`disable()`).
- `metadata.json` — uuid, версии оболочки.
- Проверка после изменений: `node --check --input-type=module < extension.js`, логи расширения — в журнале GNOME Shell (`journalctl /usr/bin/gnome-shell`).
